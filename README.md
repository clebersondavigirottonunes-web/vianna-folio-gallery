# Vianna Architectural Showcase

QUERO CRIAR UM CATÁLOGO / PORTFÓLIO INSTITUCIONAL DA VIANNA VIDROS E ESQUADRIAS.

IMPORTANTE: ESTE PROJETO NÃO É UM SITE, NÃO É UM SISTEMA E NÃO É UM DASHBOARD.

Quero criar uma experiência VISUAL DE CATÁLOGO DIGITAL, com aparência de uma revista/catálogo profissional de arquitetura, que posteriormente possa ser exportada ou impressa em PDF.

O resultado deve parecer um MATERIAL GRÁFICO PROFISSIONAL, e não uma interface de software.

==================================================
REFERÊNCIA VISUAL
==================================================

Vou anexar um PDF da Bazze PVC.

ANALISE O PDF ANEXADO COM ATENÇÃO.

Use o PDF como principal referência de:

- estrutura editorial;
- composição das páginas;
- hierarquia visual;
- proporção entre textos e imagens;
- estilo de apresentação dos produtos;
- uso de fotografias;
- páginas institucionais;
- páginas de diferenciais;
- páginas de cores e acabamentos;
- ritmo visual;
- utilização de títulos grandes;
- organização de informações;
- sensação de catálogo premium.

NÃO COPIE a Bazze.

Não copie:
- textos;
- logotipo;
- identidade visual;
- nomes;
- imagens;
- cores específicas da marca;
- layout exatamente igual.

Quero criar uma INTERPRETAÇÃO ORIGINAL desse tipo de catálogo para a VIANNA VIDROS E ESQUADRIAS.

==================================================
OBJETIVO
==================================================

Criar um catálogo institucional / portfólio comercial da Vianna Vidros e Esquadrias.

Esse material será apresentado para:

- clientes;
- arquitetos;
- engenheiros;
- construtoras;
- incorporadoras;
- designers;
- profissionais da construção.

O material precisa transmitir:

QUALIDADE
EXPERIÊNCIA
PRECISÃO
CONFIABILIDADE
SOFISTICAÇÃO
PROFISSIONALISMO

A sensação deve ser de uma empresa consolidada e especializada em projetos de arquitetura.

==================================================
FORMATO
==================================================

Criar o projeto pensando em páginas individuais de um catálogo.

Formato:

A4 vertical.

Cada seção deve funcionar como uma PÁGINA DE CATÁLOGO.

Não criar uma interface tradicional de site.

Não usar:
- navbar de site;
- dashboard;
- cards de aplicativo;
- tabelas de sistema;
- sidebar;
- menus complexos;
- aparência de SaaS;
- botões excessivos.

A navegação pode existir apenas como recurso secundário para visualizar as páginas.

A prioridade absoluta é a COMPOSIÇÃO GRÁFICA DAS PÁGINAS.

==================================================
DIREÇÃO DE ARTE
==================================================

Quero um catálogo com estética:

- arquitetura contemporânea;
- alto padrão;
- minimalista;
- sofisticada;
- editorial;
- elegante;
- limpa;
- moderna.

Imagine uma revista de arquitetura premium.

Usar:

- fotografias grandes;
- páginas quase inteiras com fotografia;
- títulos grandes;
- textos curtos;
- bastante espaço negativo;
- linhas finas;
- blocos tipográficos;
- números grandes;
- composição assimétrica;
- detalhes gráficos discretos.

Não transformar tudo em cards.

Não colocar todos os conteúdos dentro de caixas.

Quero uma composição EDITORIAL.

==================================================
IDENTIDADE VIANNA
==================================================

Nome:

VIANNA VIDROS E ESQUADRIAS
